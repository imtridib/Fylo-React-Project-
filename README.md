# Fylo — React Landing Page Practice

A React front-end practice project based on the Fylo landing-page concept. The repository uses React and React Icons with Create React App.

## Tech stack

- React 18
- JavaScript
- React Icons
- Create React App

## Run locally

```bash
npm install
npm start
```

Open the local development URL shown by Create React App (normally `http://localhost:3000`).

## Production build

```bash
npm run build
```

## Status

This repository is a front-end learning project. Review the current components and styling for the exact sections implemented.
